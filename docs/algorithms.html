Swarm Algorithms (10 Built-in)

All algorithms implement the BaseAlgorithm interface, generating velocity vectors from the collective SwarmState.

  • Reynolds Boids: Classic separation, alignment, and cohesion.
  • Formation Flight: Geometric shapes (Line, V, Grid, Ring, Helix).
  • Hover Swarm: Fixed-point station keeping baseline.
  • PSO Search: Particle Swarm Optimization with global best tracking.
  • ACO Path Planning: Ant Colony pheromone trail waypoints.
  • Consensus: Distributed rendezvous and coverage.
  • Artificial Potential Fields: Goal attraction plus obstacle/peer repulsion.
  • Artificial Bee Colony: Foraging dynamics with Employed, Onlooker, and Scout roles.
  • Voronoi Coverage: Lloyd's algorithm for optimal spatial dispersion.
  • MARL (PPO): Multi-agent reinforcement learning using a shared PPO policy.
