Swarm Algorithms

Overview of built-in behaviors and how to use them as baselines.

  • Flocking (Reynolds Boids)
  • Formation planners
  • Consensus / Coverage
  • PSO, ACO, ABC
  • Artificial Potential Fields (APF)

Battle Mode

Competitive multi-team simulation with kinetic elimination and live scoring. Useful for adversarial MARL and safety testing.

Reinforcement Learning

Gymnasium-compatible environments for single and multi-agent RL. Includes `RLSwarm-v0` and `MARLSwarm-v0` with example training scripts.

Dashboard & Telemetry

FastAPI + Plotly dashboard for live visualization, SSE streaming, and run comparison. Telemetry exports to NPZ for offline analysis.

Evaluation & Benchmarks

Built-in benchmark suite, emergence metrics, and JSON reports for automated comparisons.

Examples

Placeholders for demo scripts: hover, formation, battle, and training examples.
